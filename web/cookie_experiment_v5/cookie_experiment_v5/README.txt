변경사항
- 실험 웹사이트 표시 영역을 더 크게 확장했습니다.
- 쿠키 배너를 브라우저 화면 정중앙의 modal로 고정했습니다.
- 쿠키 선택 전에는 배경 클릭과 스크롤이 차단됩니다.
- 쿠키 선택 후 스크롤이 활성화됩니다.
- 다음 웹사이트 버튼은 각 사이트의 맨 아래에 있으며, 쿠키 선택 완료 후에만 표시/활성화됩니다.
- Easy/Hard 쿠키 배너는 Easy 기준 동일 너비 및 3열 배치를 유지합니다.
- decision_time_ms는 배너 표시부터 쿠키 선택 완료까지만 측정됩니다.
